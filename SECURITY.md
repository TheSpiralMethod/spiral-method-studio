# Security Policy

## Supported Versions

This project is an early-stage, actively developed website (main branch only).
There are no older maintained versions at this time.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository (for example,
exposed credentials, dependency vulnerabilities, or unsafe handling of user
input), please report it responsibly:

1. Do **not** open a public GitHub issue for security vulnerabilities.
2. Email **ivan@thespiralmethod.life** with a clear description of the issue,
   steps to reproduce, and potential impact.
3. You can expect an initial response within 5 business days.
4. Once a fix is confirmed, we will credit the reporter (if desired) in the
   release notes.

## Scope

This policy covers the source code in this repository (the website codebase).
It does not cover the hosting/deployment infrastructure or third-party
services the site may integrate with in the future.

## Our Commitment

As a solo-maintained project, we take security seriously and aim to keep
dependencies updated and to avoid committing secrets or credentials to the
repository history.
